# Personal Portfolio Website

## Overview

This is my personal website: an interactive portfolio where I share my work, skills, and experience.

## Features

- Animated skill trees with hover-driven power-up effects
- Project cards with hover previews and device mockups
- Work experience timeline
- About section with highlights
- Contact form with client-side validation
- Multi-language support (English, Farsi, Arabic) with RTL layout
- Responsive layout for mobile and desktop
- Scroll-triggered section reveals
- Accessibility support (keyboard navigation, ARIA, skip links)
- Vite-based build with Jest tests

## Installation

### Prerequisites

- Node.js 16+
- npm or yarn

### Setup

1. Clone the repository:

```bash
git clone https://github.com/yourusername/portfolio-showcase.git
cd portfolio-showcase
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Build for production:

```bash
npm run build
```

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
- `npm run format` - Format code with Prettier
- `npm run test` - Run tests
- `npm run test:watch` - Run tests in watch mode
- `npm run analyze` - Analyze bundle size
